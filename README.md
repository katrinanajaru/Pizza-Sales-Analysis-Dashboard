# 🍕 Pizza Sales Analysis Dashboard

## 📊 Project Overview

The **Pizza Sales Analysis Dashboard** is an interactive Power BI dashboard designed to provide a comprehensive overview of pizza sales performance.

The dashboard transforms pizza sales data into meaningful business insights by analyzing sales volume, orders, product categories, pizza sizes, pricing, and monthly sales trends.

The goal of the project is to help business stakeholders monitor sales performance, understand customer preferences, identify high-performing pizza categories, and make data-driven business decisions.

## 🎯 Project Objectives

The main objectives of this project are to:

* Monitor overall pizza sales performance
* Track total sales and total orders
* Analyze the quantity of pizzas sold
* Monitor average unit price
* Identify the number of pizza types available
* Compare sales performance across pizza categories
* Analyze monthly sales trends
* Understand customer preferences by pizza size
* Provide an interactive dashboard for business decision-making

## 📂 Dataset

The dataset contains pizza sales transaction data used to analyze product and sales performance.

Key fields include:

* Order ID
* Order Date
* Order Time
* Pizza Name
* Pizza Category
* Pizza Size
* Quantity
* Unit Price
* Total Price

The dataset allows the analysis of sales performance across different products, categories, sizes, and time periods.
